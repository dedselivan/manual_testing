# Определяем методы, типы и уровни тестирования

**Задача: В рамках курса Udemy ["Тестировщик с нуля 2025"](https://www.udemy.com/course/qaengineer/) была поставлена задача:**

**Описание проекта:**

1. Интернет-магазин – это веб-приложение, которое позволяет пользователю регистрироваться, авторизоваться, изучать каталог, добавлять товары в корзину, формировать заказы и оплачивать их.

2. У приложения есть графический интерфейс и программные интерфейсы, база данных.

3. Приложение должно работать во всех популярных браузерах и операционных системах, как на компьютере, так и на мобильных устройствах.

4. Приложение на русском языке, локализация на другие языки не требуется.

5. Для его разработки дизайнер изучил все современные требования к удобству использования и пользовательскому опыту.

6. Нагрузка на приложение предполагается около 1000 пользователей в минуту. Также приложение разрабатывается с учетом требований GDPR.

7. У тестировщиков на проекте есть доступ к коду и автотестам.

**Задание:**
1. Какие методы тестирования будут использованы для данного приложения?

2. На каких уровнях может проводиться тестирование данного приложения?

3. Какие функциональные и нефункциональные типы тестирования могут быть использованы для данного приложения?
