# Тест-дизайн: форма регистрации (логин + пароль)

**В рамках курса Udemy ["Тестировщик с нуля 2025"](https://www.udemy.com/course/qaengineer/) была поставлена задача:**<br>

**Описание:**
 Как новый пользователь, я хочу создать аккаунт на сайте, чтобы иметь доступ к персонализированным функциям и содержанию.


**Критерии приемки:**

- Пользователь должен ввести имя пользователя и пароль для создания аккаунта.

- Имя пользователя может содержать от 3 до 15 символов и может включать буквы, цифры и символы: _.

- Пароль должен содержать не менее 8 символов, включая минимум одну букву и одну цифру.

- При успешной регистрации кнопка “Войти” заменяется на кнопку “Выйти”.
