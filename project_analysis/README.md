# Анализ для планирования регрессионного тестирования

В рамках курса Udemy ["Тестировщик с нуля 2025"](https://www.udemy.com/course/qaengineer/) была поставлена **задача**:

> На основе метрик качества (приоритет фичи, динамика багов, наличие автоматизации) определить, какие функции должны войти в регрессионный набор.

## Что я сделал
- Проанализировал 11 фич по 4 критериям: приоритет, стабильность, автоматизация, бизнес-критичность.  
- Принял решение по каждой фиче: включать в регрессию / не включать / частично.
