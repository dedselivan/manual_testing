# Баг-репорт: отсутствие автоматической авторизации после регистрации

**Инструмент**: Jira (формат отчёта) + testIT (связь с тест-кейсами)  
**Приложение**: [demoshopping.ru](https://intern.demoshopping.ru/)  
**Требование**: [ID1 — Регистрация пользователя](https://rusau.kaiten.ru/p/d/5b275ec1-e6df-47a4-9648-d422f4a387f3)

## Суть проблемы
После успешной регистрации новый пользователь **не авторизуется автоматически** и остаётся на странице регистрации. Это нарушает ожидания пользователя и требование: *«При успешной регистрации кнопка "Войти" заменяется на кнопку "Выйти"»*.

## Связь с тестированием
Баг воспроизводится в 4 тест-кейсах из testIT:
- #95 «Успешная регистрация валидными данными»
- #96 «Валидация логина (минимальная длина)»
- #98 «Валидация логина (максимальная длина)»
- #103 «Валидация пароля в форме регистрации — минимальная длина (8 символов)»

> 💡 **Вывод**: Проблема системная — не зависит от конкретных данных регистрации. Требует исправления на уровне бэкенда (отсутствует установка сессии после регистрации).
