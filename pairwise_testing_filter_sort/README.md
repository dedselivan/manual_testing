# Попарное тестирование: фильтрация и сортировка


**В рамках курса Udemy ["Тестировщик с нуля"](https://www.udemy.com/course/qaengineer/) была поставлена задача:**<br>

**Описание:** Требования [фильтрации](https://rusau.kaiten.ru/p/d/5b275ec1-e6df-47a4-9648-d422f4a387f3) и [сортировки](https://rusau.kaiten.ru/p/d/705e06d8-971f-4e0a-b8de-7e13befcc7a3). Оптимизировать тестирование функционала фильтрации и сортировки в интернет-магазине, так как полное тестирование невозможно. 

**Задача**: Создать таблицу с двумя вкладками: исходные данные и тестируемые значения после применения алгоритма.
